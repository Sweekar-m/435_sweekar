# To-Do List Application

A Next.js App Router to-do app built for WAF-II Experiential Learning — Project 3.

## Core concepts
- React Hooks: useState and useEffect
- State management: tasks, filters, and completion updates
- Client-side rendering: interactive task management in a Client Component

## Features
- Add, complete, delete, and clear completed tasks
- Persist tasks in browser localStorage
- Filter All / Active / Completed
- Task counts and progress indicator
- Responsive layout

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000/todos.

## Build check
```bash
npm run build
```
